# Psychologist Website – Frontend

Frontend for a psychologist website built with React and connected to a Django backend.  
The project focuses on form handling and frontend–backend communication.

## Tech Stack
- React
- JavaScript (ES6+)
- Axios
- Tailwind CSS

## Features
- Form handling with controlled inputs
- Sending data to Django backend via API
- Clean and structured React components
- Full integration with backend services

## How to run locally

npm install  
npm run dev  

Make sure the Django backend server is running for the form to work.
